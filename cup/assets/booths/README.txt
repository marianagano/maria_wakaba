出展ブース用画像フォルダ
------------------------------------------------------------
このフォルダに以下のファイル名で画像を置いてください。
index.html がそれぞれを直接参照します。

booth-1.jpg     … 出展企業A の写真 or ロゴ（4:3 推奨, 1200×900px 程度）
booth-2.jpg     … 出展企業B
booth-3.jpg     … 出展企業C
booth-4.jpg     … 出展企業D

------------------------------------------------------------
カードを増やしたい時
------------------------------------------------------------
1. このフォルダに booth-5.jpg, booth-6.jpg, ... を追加
2. index.html の <!-- ▼ 出展企業1件 = 1ブロック ... ▲ ▲ ここまで --> の間にあるカードを
   コピペして、画像パス・タグ・名称・説明を書き換える

------------------------------------------------------------
カードを減らしたい時
------------------------------------------------------------
不要な <article class="booth-card"> ... </article> ブロックを丸ごと削除

------------------------------------------------------------
タグ（カテゴリ）
------------------------------------------------------------
data-tag="飲食"   → ライムイエロー
data-tag="物販"   → ライトブルー
data-tag="体験"   → オレンジ
それ以外         → デフォルト（ライムイエロー）。色を増やしたい場合は css/style.css の
                   .booth-tag[data-tag="..."] を追加

------------------------------------------------------------
画像なしの場合
------------------------------------------------------------
画像ファイルが無い時は、暗い背景の上に "LOGO / PHOTO" というプレースホルダー文字が
表示されます。表示が崩れることはありません。

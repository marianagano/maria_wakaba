スポンサー様ロゴフォルダ
------------------------------------------------------------
ファイル名: cohost-N.<ext>  （N: 1,2,3,...）
拡張子は jpg / png / webp / svg いずれも可（index.html 内のパスと一致させる）

現在の配置（7社）:
  cohost-1.png   … ALGOMATIC DYNAMICS 様 ※ AlgomaticDynamics_uniform.ai より生成（背景透過）
  cohost-2.jpg   … hummel 様
  cohost-3.jpg   … 豚珍館 様
  cohost-4.jpg   … Honrado International 様
  cohost-5.png   … Lpa (Lovely partner) 様 ※ エルパロゴ.pdf より自動生成
  cohost-6.jpg   … 株式会社twentytwo 様
  cohost-7.png   … ショッピングシティ ベル 様 ※ ベルロゴ.pdf よりロゴ部分を切り出し生成

エルパロゴ.pdf / ベルロゴ.pdf は原本としてフォルダに残しています（参照用）。

------------------------------------------------------------
注意：拡張子変更時の手順
------------------------------------------------------------
ファイルを別拡張子で差し替える場合（例: cohost-1.webp → cohost-1.png）は、
index.html の <span class="cohost-img"> の url() 内のパスも合わせて更新する必要があります。
拡張子が不一致だと画像が読み込まれません。

------------------------------------------------------------
推奨スペック
------------------------------------------------------------
- 比率：横長 3:2 程度を推奨（自動的にcontainされるので比率違いでも崩れない）
- サイズ：横 600px 程度（Retina対応なら 1200px）
- 背景：白 or 透過

------------------------------------------------------------
ロゴ枠を増減したい時
------------------------------------------------------------
- 増やす：cohost-5.png 以降を追加し、index.html の <div class="cohost-cell">
         ブロックをコピペして aria-label と画像番号・ファイル名を更新
- 減らす：不要な <div class="cohost-cell"> ... </div> ブロックを丸ごと削除

グリッドは自動で折り返します（PC: 4列 / タブレット: 3列 / スマホ: 2列）。

------------------------------------------------------------
リンクを設定したい場合
------------------------------------------------------------
クリックで企業サイトに飛ばしたい場合は <div class="cohost-cell"> を
<a class="cohost-cell" href="https://example.com/" target="_blank" rel="noopener">
に変更してください（hover効果が有効になります）。
